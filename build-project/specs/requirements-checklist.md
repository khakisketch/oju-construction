# Requirements Checklist (개발 전 확인사항)

## 개요

**새 프로젝트 시작 시 고객에게 확인해야 할 모든 요구사항 체크리스트**입니다.

LLM이 이 문서를 읽고 사용자에게 질문하여 프로젝트를 맞춤 설정합니다.

## 🤖 LLM 사용 가이드

### 프로젝트 시작 시 프롬프트

```
"build-project/specs/requirements-checklist.md를 읽고,
 사용자에게 다음 정보를 대화형으로 물어봐줘:

 필수 항목:
 - 프로젝트 이름, 회사명, Firebase Project ID
 - 연락처 (이메일, 전화번호)
 - Figma 파일 여부
 - 견적 모달 필요 여부 및 수집 항목
 - Contact 폼 추가 필드

 선택 항목:
 - 브랜드 컬러, 로고
 - 추가 페이지
 - 마케팅 스크립트
 - 커스텀 도메인

 답변을 받으면 build-project/scripts/init-project.js를
 실행할 수 있도록 값을 정리해줘."
```

### 견적 모달 커스터마이징 프롬프트

```
"고객이 견적 모달에서 수집하고 싶은 데이터:

- 이름 (필수)
- 이메일 (필수)
- 전화번호 (필수)
- 회사명 (선택)
- 서비스 종류 (드롭다운): ['웹 개발', '모바일 앱', '브랜딩']
- 예산 범위 (드롭다운): ['500만원 이하', '500-1000만원', '1000-2000만원']
- 프로젝트 설명 (textarea, 필수)

build-project/templates/quote-modal-template.md를 참고해서
features/home/hero/QuoteModal.tsx를 생성해줘.

build-project/specs/data-models.md의 QuoteData 모델도 함께 업데이트."
```

## 📝 체크리스트 완료 확인

프로젝트 시작 전 다음 항목이 모두 준비되었는지 확인:

- [ ] 프로젝트 기본 정보 (이름, 회사명, 연락처)
- [ ] Firebase 프로젝트 생성 (또는 생성 예정)
- [ ] Figma 디자인 또는 기본 템플릿 사용 결정
- [ ] 견적 모달 필요 여부 및 수집 항목 확정
- [ ] Contact 폼 필드 확정
- [ ] 마케팅 스크립트 ID 수집 (필요 시)

**모두 준비 완료 → `npm run init` 실행 가능!**
