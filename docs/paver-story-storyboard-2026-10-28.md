## 접근성·대체 경로

- `<ol>` 전체 이야기: 클릭 없이 읽힘. 자막(`aria-live`) + 단계 버튼(영상 준비 후 활성화).
- `prefers-reduced-motion`·짧은 화면: 스티키 해제, 버튼 점프(영상 탐색, 자동재생 없음). 낮은 가로 화면에서도 단면을 화면 안에 맞추고 설명과 범례를 그림 밖에 둔다.
- 영상 실패: 대표 정지 화면 + 안내 + 전체 글. 단계 버튼·긴 고정 스크롤과 안내를 숨긴다.
- no-JS: 정적 SVG 1개 + 전체 목록으로 읽힘(포스터 중복 표시 없음). 영상·칩·자막·버튼 숨김.
- 작은 화면에서는 그림을 가리는 칩 대신 마지막 장면의 표면·하부·배수·관로 색 범례를 그림 밖에 표시한다.
