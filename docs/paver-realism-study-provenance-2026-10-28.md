# 보도블럭 단면 정지 컷 검토 · 제작과 검증

## 승인된 작업

이전 하이브리드 시안의 아기자기한 모형 느낌과 부족한 사실성을 개선하기 위해,
같은 구도의 하부 지지 상태·침하 상태 정지 컷 두 장을 먼저 만든다. 기존 시안과
공식 `/`, `/renewal-b`는 보존한다. 이번 작업은 영상 제작이나 공식 적용이 아니다.

검토 페이지: `docs/renewal-b-paver-realism-stills-2026-10-28.html`.
작업 계약: `docs/paver-realism-study-brief-2026-10-28.md`.
렌더 소스·세부 조건·근사치는 `docs/paver-realism-render-notes-2026-10-28.md`가 소유한다.

## 출처와 권리 범위

- 새로운 형상과 조명은 Blender에서 제작하며, 실제 현장 스캔·사진·도면이 아니다.
- 재사용할 수 있는 AI 질감은 기존 `docs/images/paver-hybrid/`의 RealVisXL V5.0
  생성 이미지다. 해당 모델·SDXL VAE·시드·가공·해시는
  `docs/paver-hybrid-provenance-2026-10-28.md`에 기록되어 있다.
- 제작자 정보에서 상업적 이미지 이용 허용과 무표기 불허 설정을 확인했으므로
  검토 페이지에도 `RealVisXL V5.0 · SG_161222`, `SDXL VAE · Stability AI`를 명시한다.
  이는 전체 결과물의 무침해 보증이나 법률 자문이 아니다.
- 검증되지 않은 모델·외부 생성 API·현장 사진은 새로 추가하지 않는다.

## 해석의 한계

그림의 치수·층 구성·공동·관로·침하는 설명을 위한 조건부 예시다. 줄눈 침투 자체는
결함이라는 뜻이 아니며, 관로를 통한 유실은 여러 가능한 원인 중 하나다. 고임에는
기울기·배수구 등 다른 원인도 있다. 실제 원인과 보수 방법은 현장 기술 검토가 필요하다.

실제 현장 촬영·구조 검수·하중 해석·유체 또는 지반 시뮬레이션·실적 증빙은 없다.
사실적인 표현과 기술적 정확성의 검증을 구분한다.

### 동작 검증과 한계

- Chrome 155, Firefox 150.0.2, Linux WebKit 26.4에서 모의 1440×900,
  390×844, 320×700(스크립트 비활성), 568×320(움직임 줄이기) 화면을 확인했다.
  두 그림·대체 설명·주의사항과 전화 링크가 있으며, 가로 넘침과 페이지 오류는 없었다.
- 본문 바로가기·원본 링크의 키보드 순서와 포커스를 확인했다. 각 브라우저의
  데스크톱 axe 검사에서 위반·판정 미완료 항목은 없었다. 이것은 접근성 인증이나
  실제 스크린리더 시험을 의미하지 않는다.
- 그림 요청을 모두 차단하고 스크립트를 꺼도 상태별 제목·그림 대체 설명·본문·
  문의 안내가 남는 것을 Chrome 모의 모바일에서 확인했다.
- 다른 브라우저 검사의 초기 실행은 `document.fonts.ready`를 기다리다 시간 초과했다.
  검사의 글꼴 대기를 명시적 10초 제한으로 고친 뒤 세 브라우저 검사를 통과했다.
  페이지 코드에는 스크립트가 없으며 문의 양식·전송 기능도 없다.
- 실제 휴대전화·macOS/iOS Safari·색 관리 환경·스크린리더·고객 사용성 검증은 없다.

### 시각 검토 결과

독립 검토의 최종 판단은 **정지 컷 비교 검토물로 한정한 SHIP**이다. 이전의
미니어처 받침대·납작한 관로·반복 삼각 면은 개선됐고, 지지·침하 상태를 비교할
수 있다. 다만 **현장 사진 수준의 사실성은 아니다**. 물 반사, 단면 가장자리,
밝은 골재와 흙 표현에는 설명용 CG의 한계가 남아 있다. 이 검토는 공식 B안 적용,
영상 제작 승인, 현장 원인·공법 검수 또는 전체 사이트 승인으로 확대하지 않는다.

DESIGN.md는 `/renewal` 전용 문서이므로 변경하지 않았다. 새 페이지는 기존 B의
네이비·Noto Sans KR와 합성 이미지 고지 원칙을 계승한 별도 검토물이다.
