# 로컬 AI 영상 4차 비교 · 공유와 검증 기록

## 범위와 결과

`docs/paver-ai-video-fourth-review-2026-10-29.html`은 영상 후보 22–27을 직접
재생하는 임시 비교 도구다. 여섯 편 모두 최종 스크롤 설명 시안에 미채택이다.
이 페이지의 검토 가능 판정은 영상·공식 페이지·최종 인터랙션이나 현장 기술의
승인이 아니다. 후보 영상은 AI 예시이며 실제 현장·시공 실적·물리 시뮬레이션이 아니다.

24·25번은 중앙 줄눈의 아래 방향 움직임이 보이지만 블럭도 휘어지는 결과다.
22·23·27번은 기존 Blender 렌더에서 만든 **움직이는 안내**를 AI 조건으로 사용했고,
표시된 것은 그 안내가 아니라 새로 추론한 영상이다. 24번은 AI 표면의 시작·끝
근사 이미지와 시간 마스크를 조건으로 했으며, 25·26번은 2D 워프를 이용한
움직이는 안내를 사용했다. 안내는 실제 물리 모델이 아니고 정확한 프레임 고정이나
강체 운동을 보장하지 않는다. 같은 시드의 무조건 대조를 하지 않았으므로 관찰된
변화만으로 제어의 인과 효과를 단정하지 않는다.

## 출처

- 제어 영상·마스크의 실제 의미와 생성 방식, 모델·프롬프트·시드·워크플로·해시와
  영상별 실패 사유는 `docs/paver-video-ai-provenance-2026-10-28.md`의 4차 시험과
  `docs/ai-workflows/paver-video-ai-2026-10-28/`에 기록되어 있다. Wan2.1 VACE 14B의
  라이선스 표기는 Apache-2.0이다. 기준 이미지의 RealVisXL V5.0 제작자
  **SG_161222**와 SDXL VAE 출처도 페이지 푸터에 명시했다. 법률상 권리 보증은 아니다.
- 여섯 MP4는 각각 640×384, 33프레임, 2.0625초이며 `ffprobe`로 모두 영상 스트림만
  있고 음성 스트림이 없음을 확인했다. 포스터는 각 MP4의 1.75초에서 ffmpeg로 추출한
  WebP다. `.webp.json` 사이드카에 원본 MP4 해시·모델·워크플로를 기록했고,
  `embed-prompt --scan`은 여섯 파일 중 누락 0개였다. 비교용 표본이지 최종 프레임은 아니다.

## 공유와 검증

- 기존 **Tailscale tailnet 전용** 임시 공유에 새 파일만 추가했다.
  <https://dgx-spark-1.tailda9552.ts.net:10021/b-paver-ai-video-fourth-review.html?v=20261029-fourth1>
- HTML·영상 6개·포스터 6개·사이드카 6개는 HTTPS 응답 200 및 로컬 원본과
  SHA-256 일치를 확인했다. HTML 해시는
  `af6a43cb369db102abbb69d1127e49f979a9636251245e94585fb1634dc137a9`이다.
  개별 공유 파일 해시는 `.next/paver-ai-video-acceptance/fourth-review-shared-hashes.json`에
  있다. 기존 1–3차 비교·하이브리드·정지 컷 공유 페이지의 해시는 변경 전과 같다.
  서버 설정·공식 페이지 변경, 배포·커밋·푸시는 없었다.
- Chrome 155와 Firefox 150.0.2의 모의 1440×900, 390×844, 320×700 무스크립트,
  568×320 움직임 줄이기에서 레이아웃과 설명·포스터·링크를 확인했다. 데스크톱
  두 브라우저 및 tailnet Chrome 모의 모바일에서 여섯 영상이 각각 0.1초 이상
  재생되었다. 실제 사람이 전체 영상을 실시간으로 시청했다는 뜻은 아니다.
- Linux Playwright WebKit 26.4에서는 여섯 영상을 한 컨텍스트에서 순서대로 재생하는
  자동 검사가 서로 다른 영상에서 두 번 멈췄다(`readyState=2`, `networkState=2`,
  오류 코드 없음). 별도 새 컨텍스트의 22·23번 단일 재생은 시작됐으나, 원인은
  미확인이며 전체 WebKit·iOS Safari 재생 통과로 주장하지 않는다. 네트워크 오류를
  모의했을 때 포스터·설명·직접 파일 링크는 남았지만 링크도 같은 파일이어서
  네트워크 자체의 실패 시 재생을 보장하지 않는다.
- Chrome/Firefox 데스크톱 axe 위반은 0개였고 `video-caption` 6개는 자동 판정이
  미완료였다. 여섯 MP4에는 음성 스트림이 없고 각 영상에 요약 글이 있다. 키보드
  본문 바로가기를 확인했으며 실제 스크린리더·휴대전화·고객 시험은 하지 않았다.
- 독립 검토에서 '안내' 제목이 안내 원본과 생성 결과를 혼동시킬 수 있다고 지적해
  여섯 제목을 '조건'으로 명확히 고쳤다. 재캡처에 대한 같은 검토자의 **PASS**는
  이 문구 수정과 임시 비교 도구에 한정되며 후보나 최종 시안의 승인으로 확대하지
  않는다. 도구가 표시한 섹션 가장자리 경고는 전체 폭 배경에 대한 것으로, 실제
  `.wrap`은 좌우 데스크톱 32px·모바일 16px 여백을 가진다.

`DESIGN.md`의 `/renewal` 전용 세계관은 변경하지 않았다.
