# 로컬 AI 영상 3차 비교 · 공유와 검증 기록

## 범위

`docs/paver-ai-video-third-review-2026-10-29.html`은 더 큰 Wan2.2 A14B 모델로 만든
후보 13–21을 원본 그대로 재생하고 한계를 비교하는 임시 검토물이다. 13–19는
기준 이미지로 시작한 I2V, 20–21은 텍스트에서 시작한 T2V다. 아홉 편 모두
완성된 스크롤 설명 영상으로 채택하지 않았다. 비교 페이지의 검토 가능 판단은
어느 후보나 공식 B안, 최종 인터랙션에 대한 승인 또는 실제 기술 검수를 뜻하지 않는다.

영상은 AI로 생성한 예시다. 관로·공동·지층과 움직임은 실제 현장·시공 실적·물리
시뮬레이션이나 정확한 원인·공법의 증거가 아니다. 관로 틈을 통한 재료 유실은
조건부 가능성이며 고임에는 기울기·배수구 막힘 등 다른 원인도 있다.

## 출처와 범위

- 모델의 제공자·라이선스·고/저노이즈 FP8 가중치·해시, 기준 이미지, 프롬프트,
  시드, 워크플로, 실제 생성 시간과 후보별 관찰은
  `docs/paver-video-ai-provenance-2026-10-28.md`의 3차 시험을 참조한다.
  후보 13–19의 RealVisXL 기준 이미지에는 `SG_161222` 출처 표기 조건이 있으며
  비교 페이지 푸터에도 표시했다. 법률상 최종 권리 보증은 아니다.
- 시작 이미지만 사용하는 I2V를 실행했다. 원하는 변화가 담긴 동일 구도의 시작·끝
  이미지를 확보하지 못해 **끝 프레임으로 조건을 건 VACE 실험은 실행하지 않았다**.
  모션 마스크나 끝점 준수는 검증된 사실이 아니다.
- `ffprobe`로 13번은 512×320·33프레임·2.0625초, 14–21번은
  640×384·49프레임·3.0625초임을 확인했다. 모두 영상 스트림만 있고 음성은 없다.
- `docs/media/paver-ai-third-review-2026-10-29/` 포스터는 13번 1.75초,
  나머지 2.75초에서 ffmpeg로 추출한 WebP다. 각 `.webp.json` 사이드카에 원본 MP4
  SHA-256, 모델과 워크플로를 기록했으며 출처 검사에서 9개 중 누락 0개였다.
  이것들은 품질 검토용 표본이며 최종 시안 프레임이 아니다.

## 공유와 검증

- 기존 **Tailscale tailnet 전용** 임시 공유에 새 이름으로만 추가했다.
  <https://dgx-spark-1.tailda9552.ts.net:10021/b-paver-ai-video-third-review.html?v=20261029-third1>
- HTML, 영상 9개, 포스터 9개와 사이드카 9개의 HTTPS 응답 200 및 로컬 원본
  SHA-256 일치를 확인했다. HTML SHA-256은
  `e7d13a6dcef772e4e7abb280fe16393908a164f9bfd151c044f450313a6a4118`이다.
  개별 파일 해시 증거는 `.next/paver-ai-video-acceptance/third-review-shared-hashes.json`에
  있다. 1·2차 비교 페이지, 기존 하이브리드 시안과 정지 컷 검토 페이지의 해시는
  변경 전과 같다. 서버 설정·공식 페이지 변경, 배포·커밋·푸시는 없었다.
- Chrome 155, Firefox 150.0.2, Linux Playwright WebKit 26.4에서 모의 1440×900,
  390×844, 320×700 무스크립트, 568×320 움직임 줄이기를 검사했다. 설명·포스터·
  파일 링크·전화가 남고 가로 넘침은 없었다. 데스크톱 세 브라우저 및 tailnet의
  Chrome 모의 모바일에서 아홉 영상이 각각 0.1초 이상 재생되었다. WebKit의 첫 전체
  검사에서는 재생 대기 시간 초과가 한 번 있었고 재실행은 통과했다. 실제 모든
  Safari 기기에서의 재생을 보장하지 않는다.
- Chrome 모의 모바일에서 영상 요청을 차단해 포스터·설명·직접 링크를 확인했으며,
  링크도 동일 파일이므로 네트워크 자체가 막히면 재생을 보장하지 않는다.
  본문 바로가기 키보드 포커스도 확인했다. 데스크톱 axe 위반은 0개, 자동 판정
  미완료는 무음 영상 `video-caption` 9개였다. 실제 스크린리더·휴대전화·고객 검증은
  없으며, 재생 시작 검사는 전체 영상을 사람이 실시간으로 시청했다는 의미가 아니다.
- 독립 시각 검토의 **SHIP**은 3차 비교 도구에 한정된다. 포스터·관찰·AI 고지·
  모바일 배치의 검토이지 아홉 영상의 승인이나 원래 목표의 완료 판정이 아니다.
