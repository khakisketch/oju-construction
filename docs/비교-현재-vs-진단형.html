이미지·영상·3D 제작 방향

  • 1차: SVG 단면도 — 지금 만든 것처럼 코드로 그립니다. 정확하고, 수정이 빠르고, 모바일에서도 선명합니다.
  • 2차: 실제 현장 촬영 — 드론 1컷, 포장 디테일 3컷, 배수·조경·시설물 각 1컷. AI 이미지보다 실제 사진이 신뢰를 더 만듭니다.
  • 3차: DGX Spark 이미지 생성 — SVG를 선화/깊이맵으로 넣고 ControlNet + FLUX/Qwen-Image로 등각 일러스트를 만듭니다. 글자는 AI에 맡기지 않고 HTML/SVG로 얹습니다.
  • 4차: 30초 설명 영상 — 실제 현장 영상 + 모션 그래픽 + 짧은 AI b-roll. Wan 2.2/LTX-Video는 5~8초 클립용으로 쓰고, 기술 설명은 모션 그래픽이 더 정확합니다.
  • 5차: 3D — 생성 3D보다 실제 현장 Gaussian Splatting이 더 설득력 있습니다. 드론/스마트폰 촬영 → DGX Spark에서 학습 → 웹 뷰어 임베드.
