# 보도블럭 단면 정지 컷 검토 · 작업 범위

사용자 피드백: 기존 단면은 아기자기한 모형처럼 보이고 사실성이 부족하다.
승인된 다음 작업: 같은 구도의 정상·침하 정지 컷 두 장을 먼저 제작한다.
이번 결과는 영상 제작 전의 시각 검토물이다. 기존 B안, 공식 페이지, 기존 공유물은
보존하며, 전체 사이트의 재설계나 새 영상 제작으로 범위를 넓히지 않는다.

## Direction contract

**THESIS:** 작은 전시 모형 대신 화면 밖으로 이어지는 실제 포장을 가까이 잘라
들여다보는 설명용 단면. 반듯한 판과 납작한 구멍에 질감만 붙이는 방법을 버린다.

**OWN-WORLD:** B안의 네이비·흰색과 한국어 Noto Sans KR를 유지한다. 이미지가
주인공인 간결한 검토 문서로, 그림 위 카드·기술 배지·장식 애니메이션을 얹지 않는다.
실제 현장 사진이나 검증된 시공 실적이라는 인상을 주지 않도록 CGI 표기를 함께 둔다.

**STORY:** 하부가 지지하는 상태와 국부 침하·물 고임 상태를 같은 카메라로
비교한다. 원인을 단정하지 않으며 관로 틈을 통한 재료 유실은 조건부 예시다.
첫 단계의 성공은 사실적인 크기감·재료·입체 깊이를 확인하는 것이지 영상 완성이 아니다.

**FIRST VIEWPORT:** 회사명과 검토물 안내, 짧은 제목 다음에 큰 침하 상태 이미지를
표시한다. 정상 상태도 별도 큰 그림으로 클릭 없이 이어서 읽힌다. 원본 이미지 링크는
보조 수단이며 본문·두 상태·주의사항은 스크립트 없이 제공한다. 모바일도 동일 순서다.

**FORM:** Read, code-led. 사용자와 앞선 대화에서 고정한 정지 컷 검토 방향이며
새 브랜드 선택은 아니다. seed: none (user-pinned local study; no concept roll).

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## 검증과 경계

- 렌더 구현은 Lead, 검토 페이지·통합·공유·최종 판단은 Build가 소유한다.
- 쓰기 범위는 새로운 렌더·이미지 폴더·정지 컷 검토 페이지와 해당 기록뿐이다.
- 이전 RealVisXL 질감은 출처 기록과 SG_161222 표기를 유지해 재사용할 수 있다.
  검증되지 않은 모델이나 생성 서비스는 추가하지 않는다.
- 실제 현장 도면, 재료 규격, 하중·유체·지반 해석 또는 공법 검수의 증거는 없다.
- 두 컷의 실제 렌더를 검토하고, 1440px·390px 및 짧은 화면에서 이미지·문장·링크를
  확인한다. CGI라는 한계와 남은 사실성 문제는 결과에 명시한다.
- DESIGN.md의 /renewal 전용 세계관을 변경하지 않는다. 새 검토물은 기존 B의
  네이비 계열을 계승하며 전역 디자인 시스템 파일을 수정할 권한은 포함하지 않는다.
