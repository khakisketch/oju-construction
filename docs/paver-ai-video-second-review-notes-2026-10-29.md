# 로컬 AI 영상 2차 비교 · 공유와 검증 기록

## 범위와 판단

`docs/paver-ai-video-second-review-2026-10-29.html`은 후보 5–12를 직접 재생하고
비교하는 별도 임시 검토물이다. 각 클립의 결함을 함께 표시하며, 이 시점에 어느
후보도 최종 시안에 채택하지 않았다. 갤러리의 검토 가능 판단은 영상·공식 B안·
프레임 인터랙션의 승인이나 실제 현장·구조 검수가 아니다. 추가 실험은 계속한다.

영상은 AI 생성물이다. 단면의 관로·공동·지층은 실제 구조나 치수의 증거가 아니며,
침하·고임의 원인을 영상만으로 판정할 수 없다. 줄눈 스밈 자체는 결함이 아니고,
관로를 통한 재료 유실은 조건부 가능성이다. 원인과 보수 범위에는 현장 기술 검토가
필요하다.

- 후보 5–7은 Wan2.1 VACE 14B, 8–12는 Wan2.2 TI2V 5B로 로컬 생성했다.
  7·8·11은 별도로 생성한 RealVisXL V5.0 기준 이미지를 사용한다. 페이지 푸터에는
  모델과 `RealVisXL V5.0 · SG_161222`, `SDXL VAE · Stability AI`를 표기했다.
- 별도로 제공자의 API를 조회해 Wan2.2 TI2V 5B 모델 카드와 Comfy-Org 재포장본의
  Apache-2.0 표기 및 기록된 5B 모델·VAE LFS SHA-256이 일치함을 확인했다. RealVisXL
  제작자 API는 상업적 이미지 이용(`Image`) 허용과 출처 미표기 불허를 나타냈다.

  10–12는 832×480·81프레임·3.375초다. `ffprobe`로 모두 영상 스트림 하나만 있고
  오디오 스트림이 없음을 확인했다.

## 임시 공유와 검증

- 기존 **Tailscale tailnet 전용** 임시 공유에 새 파일만 추가했다.
  <https://dgx-spark-1.tailda9552.ts.net:10021/b-paver-ai-video-second-review.html?v=20261029-second1>
- HTML·영상 8개·포스터 8개·사이드카 8개의 HTTPS 응답이 200이고 로컬 원본과
  SHA-256이 일치했다. HTML 해시는
  `50a7c226b6c90b3f262015c6a7666414fc6dda6ac6885b228b0fc38aee840adf`이다.
  1차 영상 비교 페이지, 기존 하이브리드 시안·영상과 정지 컷 검토 페이지의 해시는
  공유 전후 같다. 공식 배포·공유 설정 변경·커밋·푸시는 없었다.
- Chrome 155, Firefox 150.0.2, Linux Playwright WebKit 26.4에서 모의 1440×900,
  390×844, 320×700(무스크립트), 568×320(움직임 줄이기) 레이아웃을 검사했다.
  여덟 포스터·설명·직접 링크와 전화가 표시되고 가로 넘침은 없었다. 각 데스크톱
  브라우저와 tailnet Chrome 모의 모바일에서 여덟 영상이 각각 0.1초 이상 재생되었다.
  이는 사람이 전체 영상을 실시간 시청했다는 의미가 아니다.
- 영상 요청을 차단한 모의 오류에서 포스터·설명·직접 파일 링크가 남았다. 링크도
  같은 파일을 가리키므로 네트워크 자체의 실패 시 재생을 보장하지 않는다. 키보드
  본문 바로가기와 포커스는 확인했다.
- 데스크톱 axe 검사의 위반은 0개였으며, `video-caption` 8건은 자동 판정이
  미완료였다. MP4에는 음성 스트림이 없고 각 영상에 눈에 보이는 요약이 있다.
  실제 스크린리더·휴대전화·iOS Safari·고객 시험은 하지 않았다.
- 독립 시각 검토 판단은 **SHIP — 2차 비교 도구에 한정**이다. 이미지·설명·AI 및
  미채택 고지, 모바일 배열을 확인한 것이며 영상 품질이나 최종 시안의 승인이 아니다.
  검토자는 7번 시트를 따로 보지 않았으나 부모 세션이 해당 시트를 열어 문구를 확인했다.

`DESIGN.md`는 `/renewal` 전용이므로 변경하지 않았다. 이 페이지는 B의 기존 네이비와
서체를 계승한다.
