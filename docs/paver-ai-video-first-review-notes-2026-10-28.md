# 로컬 AI 영상 1차 비교 · 공유와 검증 기록

## 범위와 판단

`docs/paver-ai-video-first-review-2026-10-28.html`은 처음 생성한 네 편을 직접
재생하고 실패 이유를 비교하기 위한 임시 검토 페이지다. 네 편 모두 미채택이며,
이 페이지의 검토 가능 판정이 영상·공식 B안·프레임 인터랙션의 승인이라는 뜻은
아니다. 추가 영상 시험은 별도로 진행한다.

네 영상은 표면만 묘사하며 공동·지층·관로의 실제 상태나 침하 원인을 보여주지
않는다. AI 영상은 실제 현장, 시공 실적이나 물리 시뮬레이션이 아니다. 조건부
원인·공법은 현장 조사와 기술 검토가 필요하다.

## 영상 및 이미지 출처

- 생성 모델·가중치 출처와 해시, 라이선스, 워크플로, 프롬프트와 실험별 판단은
  `docs/paver-video-ai-provenance-2026-10-28.md` 및
  `docs/ai-workflows/paver-video-ai-2026-10-28/candidate-{1,2,3,4}.json`을 참조한다.
- 각 영상은 로컬에서 Wan2.1 VACE 14B로 생성했다. 네 MP4 모두 640×384, 49프레임,
  16fps, 3.0625초이며 `ffprobe`로 영상 스트림 하나만 있고 음성 스트림은 없음을
  확인했다. 모델 라이선스의 상업적 사용 허용은 결과물의 권리나 정확성을 보증하지
  않으며, 실제 공개 전 해당 조건을 다시 확인해야 한다.
- 포스터는 각 MP4의 2.75초 지점에서 `ffmpeg -ss 2.75 ... -frames:v 1 -c:v libwebp
  -q:v 80`으로 추출했다. 원본 영상과 모델·워크플로 출처는 포스터 옆의 `.webp.json`
  파일에 기록했다. 메타데이터 주입 도구는 WebP에서 이미지 내부 대신 사이드카를
  사용하며, 포스터 픽셀은 바뀌지 않았다. 출처 검사 `embed-prompt --scan`은 4개 중
  누락 0개였다. 이 포스터는 비교용 표본이지 최종 스크롤용 프레임이 아니다.

## 임시 공유와 검증

- 기존 Tailscale **tailnet 전용** 임시 공유에 새 파일 이름으로만 추가했다.
  <https://dgx-spark-1.tailda9552.ts.net:10021/b-paver-ai-video-first-review.html?v=20261028-first1>
- HTTPS의 HTML·네 영상·네 포스터 응답이 200이고 각각 로컬 원본 SHA-256과 일치했다.
  HTML SHA-256은 `2a6e3fd32bcfe760f5329b82347a712729888ebb2e5bf2991f16c79a315307f8`이다.
  기존 하이브리드 페이지·영상 및 정지 컷 검토 페이지는 공유 전후 해시가 같다.
  서버 설정 변경, 공식 배포, 커밋과 푸시는 없었다.
- Chrome 155, Firefox 150.0.2, Linux Playwright WebKit 26.4에서 모의 1440×900,
  390×844, 320×700(무스크립트), 568×320(움직임 줄이기) 레이아웃을 검사했다.
  네 포스터·설명·직접 링크와 전화 링크가 있고 가로 넘침은 없었다.
  데스크톱에서 각 영상이 최소 0.1초 재생되는지 확인했으며, Tailscale 공유에서도
  Chrome 모의 모바일로 같은 재생 시작을 확인했다. 이는 전체 영상을 사람이 실시간
  시청했다는 의미가 아니다.
- Chrome 모의 모바일에서 영상 요청을 차단해도 포스터·설명·직접 파일 링크가
  남는 것을 확인했다. 직접 링크도 같은 파일이어서 네트워크 자체가 실패하면
  재생을 보장하지 않는다. 키보드 본문 바로가기와 본문 포커스도 확인했다.
- 세 브라우저의 데스크톱 axe 검사에서 위반은 없었다. `video-caption` 4건은 자동
  판정이 미완료였고, 영상은 음성 스트림이 없으며 각 장면의 요약은 텍스트로
  제공한다. 실제 스크린리더·iOS Safari·안드로이드 실기기와 고객 사용성 시험은 없다.
- 초기 무스크립트 자동 검사에서는 검사 코드가 삽입한 이미지 `onload` 콜백이
  발생하지 않아 대기했다. 페이지에 스크립트는 없고, 검사를 HTTP 확인 및 실제
  화면 캡처로 바꾼 뒤 통과했다. Linux WebKit에서는 배경 화면의 `requestAnimationFrame`
  대기가 시간 초과되어 테스트 폴링 방식만 바꾼 뒤 재생 시작을 확인했다. 모든 기기에서
  재생을 보장하지 않는다.
- 독립 시각 검토 판단은 **SHIP — 1차 비교 도구에 한정**이다. 페이지의 주요 화면,
  포스터·관찰·미채택·AI 고지와 모바일 배치를 확인했으나 영상의 실시간 체감 품질이나
  사용자 승인은 검증하지 않았다. 전체 페이지 캡처에서 일시적인 기본 비디오 로딩
  표시가 보인 점도 실제 브라우저마다 지속되지 않는다고 단정할 수 없다.
- 시각 비교 도구의 준비 호출은 세션에서 원래 사용자 요청을 식별하지 못해 실패했다.
  대신 위 실제 브라우저 캡처와 네 영상의 표본 프레임을 직접 열고 독립 검토했다.

`DESIGN.md`는 `/renewal` 전용이므로 변경하지 않았다. 비교 도구는 기존 B의 네이비와
한국어 서체를 계승한 별도 검토물이다.
