# 단면 정지 컷 · 시각 검토 결과

## 범위와 판단

사용자가 지적한 '아기자기한 모형 느낌과 부족한 사실성'에 대해, 정상·침하 두
정지 컷을 같은 구도로 먼저 구성한 작업이다. 최종 독립 검토 판단은
**SHIP — 정지 컷 비교 검토물에 한정**이다. 현장 사진 수준의 사실성, 공식 페이지
적용 또는 애니메이션 제작 승인이라는 뜻이 아니다.

## 실제로 개선된 점

- 받침대가 있는 작은 모형 대신 화면 밖으로 이어지는 포장으로 크기감을 바꿨다.
- 관로 내부와 공동에 입체 깊이가 생겼으며, 정상·침하 상태의 구도가 유지된다.
- 중복 꼭짓점 때문에 반복되던 삼각 면을 수정해 블럭 윗면과 잘린 앞면이 반듯해졌다.
- 침하 상태의 앞 가장자리 처짐, 하부 빈 공간, 물 고임이 비교된다.
- 그림 위 카드·장식·자동 애니메이션 없이 큰 그림과 별도 설명으로 구성했다.

## 남은 사실성 문제

- 물은 얕은 고임과 젖음으로 읽히지만 실제 주변 사물 반사 등은 부족하다.
- 공동 가장자리와 층 경계에는 확대하면 CG식 단순화가 보인다.
- 일부 밝은 골재·흙 재질은 사진 수준이 아니며 실제 지반 구성도 검증되지 않았다.
- 작은 관로 결손은 조건부 묘사다. 공동과 유실 경로를 입증하지 않으므로
  '이 그림으로 관로 손상 여부나 재료가 유실된 경로를 판정할 수는 없습니다'라는
  본문 고지를 유지했다.

## 증거와 제한

원본 렌더 두 장, 이전 거절된 렌더 및 `.next/paver-realism-v1-acceptance/`의
실제 브라우저 캡처를 확인했다. 독립 검토는 Chrome 모의 화면의 픽셀에 근거했으며,
브라우저 동작 검증과 출처·파일 해시는 `paver-realism-study-provenance-2026-10-28.md`에
별도로 기록한다. 실제 기기·스크린리더·현장 기술 검수나 고객 승인은 없다.
